# Trilha de estudo do Nózito

Um capítulo por sprint. Cada capítulo explica **o que** foi feito, **por que**, **onde ler no código**
e traz um **exercício curto** para você mexer e ver acontecer.

Como estudar cada capítulo (≈30 min):
1. Leia a seção.
2. Abra o arquivo indicado e ache o trecho citado.
3. Faça o exercício. Se quebrar, `npm test` mostra onde.
4. Desfaça com `git checkout -- <arquivo>` (volta o arquivo ao último commit).
